# GZ-010 建立十项 POC 的统一模板、样本、资源与排程

## 背景

W1 中 GZ-004 已完成，GZ-010 是进入 W2 前仍需完成的 POC Program 基线任务。第一次 Reservation PR #42 基于 `7c78c15097046d02ce04959b56c485ef76943c49` 创建，但 Gate #374 暴露治理测试 fixture 会覆盖既有 Active Work；该 PR 已关闭且未合并。OPS-003 通过 PR #44 修复，`main@d23543f97facff00d02f79aab1693a37788765c9` 的 post-merge Governance Gate #380 全绿，因此本 v2 Reservation 只以该绿色 SHA 为新基线。

## 目标

- 建立统一、机器可读的 `POC-PROTOCOL-V1`；
- 为 POC-01～10 建立一一对应的计划文件与独立 Evidence 边界；

- 让 POC-001～010 后续 Agent 可以在不重新解释范围的情况下独立执行。

## 非目标

- 不执行任何硬件、网络、存储、云、前端、AI 或恢复实验；
- 不填写真实实验命令、测量值、PASS/FAIL 决策或 Reviewer 结论；
