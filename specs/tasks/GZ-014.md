# GZ-014 合并后测试修复分支预留

## 背景

PR #22 已合并为 `903754295e4a0393638c82aa851c3ada8cd507fb`。合并后 `main` Governance Gate run #237 的生产生命周期、Program、Coordination、Schema、Scope 与 Evidence 检查均通过，但治理测试失败。已关闭 PR #23 证明该失败来自仓库集成测试把 `origin/main == HEAD` 的 main-push 场景固定归因给 GZ-014；同时 PR #23 因未先建立新分支 Reservation、Handoff 仍指向旧分支而未合并。

## 目标

- 登记 `chore/GZ-014-test-repair-reservation-v2` 为当前唯一工作分支；
- 固定 Reservation 基线为 `main@903754295e4a0393638c82aa851c3ada8cd507fb`；

- 刷新 canonical Handoff 与 Evidence，确保中断后可从正确分支、基线和验证状态恢复；

- 后续只通过独立 Implementation PR 修复仓库集成测试，不改变生产生命周期检查器。
