# 归泽 V1 产品需求规格

## 状态

APPROVED / FROZEN

GZ-021 路线修订候选，验收绑定 revision 1；机器文档 schemaVersion 2。原十项功能与十二项仓库验收保留，按 `local-v1` 和 `production` 分别记录结果。候选经正常实现审查合入后成为本版权威；预留/治理成功不证明平台功能完成。

## 产品陈述

归泽将海量多源媒体统一抽象为逻辑资产，并提供按需访问、智能加工、统一检索、生命周期、权限和生产治理。

## 核心验收（功能共用，生产声明单独验证）

1. 本地一期确认真实 OpenList/WebDAV 与通用来源闭环；所有确认的生产数据源连接器仍须达到生产级，百度生产接入后置且不得以本地协议测试计为通过；
2. 资产、来源、版本、Rendition、Replica 模型正确；
3. 播放链路支持 Range、AV1、ABR 和临时兼容转码；
4. 全部确认 AI 流水线可追溯并通过质量门禁；
5. 搜索和推荐不泄漏权限；
6. 所有长任务可重试、暂停、恢复和取消；
7. 配置、规则、部署和升级可审批和回滚；
8. PostgreSQL、Secrets 和关键文件完成恢复演练；
9. 所有制品签名、验签、SBOM 和许可证完整；
10. Agent 修改具备证据并经人工审批发布。

## 生产约束（保留原基线）

- Agent 主开发、一人审查；
- 当前单物理宿主机；
- ESXi 6.7；
- A380 需 POC；
- 700TB 来源规模；
- 500GB 存储安全水位；
- V1 不设置对外 Beta。

## 本地 V1 验收边界

`local-v1` 覆盖 REQ-V1-0001～0010 及原十二项验收，在 GZ-019 之后由 GZ-018 完成全量本地功能/E2E、故障注入、权限隔离、恢复与供应链验收。使用真实 OpenList、数据库、编码器、播放器和已确认 AI/检索能力；成功链路不能由模拟服务代替。生产 GZ-020 的容量、硬件、来源、公网、安全和恢复发布义务保持。

编码执行从归泽解耦到 Windows/Linux/Android 工作池。归泽保留资产/版本、业务任务、权限、编码配置和发布权威；设备只执行有限编码尝试。节点身份租约与分片尝试租约分离，重领后旧代数不得发布，重复完成幂等；输出必须通过执行组配置和全片时间轴/完整性验证。

播放需求使用原 P0，近期预取同样受授权与额度控制；热门预热 P3、普通后台 AV1 P6。P1 冷恢复与 P2 用户主动加工保持。通过主体公平、播放保留容量和实际耗时调度；无法赶上播放时使用已验证兼容路径，不能让实时播放依赖未经验证的手机吞吐。

HLS manifest、初始化片段、媒体片段及热缓存均先鉴权，撤权后缓存命中也拒绝。seek 窗口有独立代数，旧窗口更新不得覆盖新需求；只发布连续 READY 区间。HLS 缓存不等于完整正式副本，淘汰不得删除资产或已保留副本。

本地容量采用明确配置且实测的正安全水位和任务空间预留，不能通过改写生产 500GB 数值取得本地通过。单机 Windows/WSL 只证明独立执行节点协调；真实手机持续编码、物理跨机、A380/ESXi、TrueNAS/iSCSI、约 700TB、公网和百度云分别保留待测/后置证据。AV1 解码、编码器枚举、模拟目录规模和服务健康不构成这些验证结果。

验收配置必须绑定权威修订、配置 ID/版本、对应里程碑、完整需求和验收范围。未知配置、版本/文件间绑定漂移、伪造生产测量、过期发布或缓存越权均拒绝。具体决定见 ADR-0015；现有 DeploymentProfile 和媒体编码配置版本仍是独立概念。

## GZ-022：智能边缘计算与产品 Agent 后续规划

本节承接异构工作池方案，为后续任务定义产品边界；生效以 GZ-022 的正常登记、完整业务定义及独立接受为准。它不改变上文冻结的 V1、十项 POC、GZ-020 生产义务，也不以规划完成、治理通过或原型结果声明节点运行时、OCR、产品 Agent 或完整 V1 已交付。

平台将已授权的视频加工请求持久化为有依赖、质量、权限和预算约束的计划，经公共执行协议交给手机及 Windows/Linux 工作节点。并行 AV1/HLS 和视频结构分析共用资源约束，保留播放优先、连续 READY、鉴权缓存及安全重派。首个结构分析闭环固定一个授权的 10–30 秒视频版本和六个采样点，返回实际解码图像及其时间、尺寸、像素格式、哈希，由平台验证并提供受权查询；六帧通过不能代替离线 OCR 的文字质量验收。产品 Agent 只能组合已验证工具并在既定权限、质量和预算内提出或调整计划，业务最终状态与结果接受仍由平台决定。

首批使用现有 OnePlus 8T（KB2000）和 Android 虚拟机，以及闲置 Windows/Linux 设备；不以 root、GPU/NPU、全天后台或实时手机 AV1 吞吐为前提。虚拟机用于可重复协议、取消和断网测试，真机分别验证能力、温升与系统生命周期。本地 OpenList/WebDAV 承接来源与存储验证，百度云生产接入后置。跨仓交付必须由各仓正式 Task 授权，并交接固定平台、协议、节点及能力包版本；材料、兼容矩阵和联合验收均须指向实际制品，不能用本文取得运行或跨仓写权限。详见 [ADR-0016](../../adr/0016-agent-edge-runtime-and-product-agent-planning.md)。
