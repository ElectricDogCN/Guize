## 运行环境预检

- Windows 原生 OpenList v4.2.6 与记录的二进制摘要一致。使用一次性目录和随机生成的测试管理员凭据启动，验证回环监听属于该进程，健康接口返回 HTTP 200 和 `pong`。预检没有挂载来源。进程及临时数据已回收。
- Python 3.12.4 与 OpenSSL 3.0.14 使用临时证书在回环地址完成 TLS 1.3 握手。客户端验证证书与 `localhost`，读回 20 字节。进程及临时证书已回收。
- [样本校验器](../../../poc/POC-07-public-network/verify_fixture.py) 读取本机原件，返回 `SAMPLE-RANGE-LARGEFILE`、67,108,864 字节及 SHA-256 `9a30d2bb1a4f1eabcb41baa5b6518628411ba8ac668fc1e7085983261aa5f419`，与 POC-003 的原始合格样本完全一致。三字节错误样本退出 1。正式运行需要本任务的样本批准。

## 联合播放路径预检

临时 OpenList 挂载了 16 KiB 合成文件，回环 TLS 代理使用本次生成的专用只读身份访问该文件。正常下载返回 HTTP 200 和相同的完整字节。Range `bytes=1024-2047` 返回 HTTP 206、准确的 `Content-Range` 和 1,024 个匹配的字节。携带源返回的当前校验值时，匹配的 If-Range 也返回 HTTP 206 和相同片段。进程、监听及临时文件均已回收。[测量原始结果](openlist-tls-range-preflight.json)

正式实验使用本任务批准的文件和服务配置，记录大文件流式读取、授权边界、缓存隔离、限流及回收结果。

## 分块读取预检

在 Windows 和 WSL 分别执行 [读取组件的五项测试](../../../poc/POC-07-public-network/test_stream_fixture.py)，覆盖分块完整传输、If-Range、开放和后缀区间、源区间错误、源提前结束。两处各五项通过。

在原生 OpenList 上挂载新的 2,097,189 字节合成文件，用读取组件与回环 TLS 代理实际执行四次传输。完整读取和旧 If-Range 各返回 HTTP 200 及原始完整摘要；Range 和匹配的 If-Range 各返回 HTTP 206、相同的 130,084 字节及区间摘要。四次实际单次读取峰值均为 65,536 字节，整个进程的内存水位留待正式实验。临时服务和文件均已回收。[实测输出](openlist-tls-bounded-streaming-preflight.json)

读取观察器的两项新增测试验证连续 64 MiB 产生 64 条读取记录，以及非对齐输入的末段摘要与输出字节一致。Windows 和 WSL 各七项通过。在原生 OpenList 的同一合成传输流程中，全量及区间分别实测 3 段和 1 段。四次传输的每段都与源文件逐段校对，读取峰值仍为 65,536 字节。[读取观察结果](openlist-tls-bounded-read-observation-preflight.json)

## 授权、缓存及实际响应采集预检

在真实 OpenList 与回环 TLS 中复用 POC-003 的 Grant 校验，让一个合成测试身份访问单一缓存区间。匹配的 If-Range 从缓存返回 130,084 字节。无身份、授权到期和其他身份均收到 403，零响应体、零缓存读取、零新增源传输。一次有界限流预检发出五个正常请求，前四个返回 206，第五个返回 429 和零字节，源传输增量为零。[限流预检](openlist-tls-bounded-rate-preflight.json)

原始响应采集器通过同一真实入口分别采集完整读取、缓存区间和未登录三次的实际 HTTP 响应。现有 POC 响应解析器重算三份响应的状态、长度和摘要，分别得到 HTTP 200 与 2,097,189 字节、HTTP 206 与 130,084 字节、HTTP 403 与零字节，三次均为已验证的 TLS 1.3。保留预检测量，临时响应文件和进程均已回收。正式执行以批准的资源、样本、采集程序和限定窗口为准。[响应采集预检](openlist-tls-raw-response-preflight.json)

对一次未登录的直接 WebDAV 样本请求，采集器从原生 OpenList 实际读得 146 字节 HTTP 响应。现有解析器核对状态为 401、响应体为零字节。临时资源已回收。[直接源响应测量](openlist-direct-origin-response-preflight.json)

复用网关与采集入口在同一次 Windows 原生 OpenList v4.2.6 环境中核对了 12 对独立的原始响应和响应体。初次 Range 读源并填充 130,084 字节缓存，匹配的 If-Range 从缓存返回同样的字节。三类身份拒绝均无缓存读取和已完成的源传输。完整读取返回 2,097,189 字节并匹配源摘要。窗口内前四次请求从缓存返回 206，第五次收到无响应体的 429，直接 OpenList 请求收到无响应体的 401。保留测量摘要，原件、证书及进程为本次一次性预检资源，已回收。正式执行保留原始响应和单独响应体并独立审核。[可复用入口预检](native-fixture-replay-preflight.json)

加入关联字段后复验同一矩阵。12 对响应和响应体各有唯一请求 ID 和追踪 ID。11 次 TLS 连接的实际证书摘要均与实验信任材料匹配。两次实际通过网关取源的请求均记录了取源时间，后续读取的时间与字节偏移连续覆盖响应。缓存命中、拒绝和限流返回中没有网关取源记录。

仓库内单命令用真实小样本及原生 OpenList 从独立进程完成预检，进程退出 0，核对了 12 对响应原件与响应体。临时读取凭据经标准输入传入，采集器的标准输出与结果文件均未包含该凭据。网关、OpenList 和临时文件均已回收。

同一仓库命令也在 Ubuntu WSL 上使用经摘要核验的 Linux OpenList v4.2.6 独立运行。12 个用例的 HTTP 状态、响应体长度和摘要与 Windows 一致。播放用例的缓存命中与已完成的源传输记录一致。两处进程均退出 0，本次 Linux 沙箱和临时文件已回收。

## 64 MiB 固定样本实测

在固定源码 `58c8919b10118ec9c0070272f6a713382b76d1aa` 上，使用 Ubuntu WSL、隔离 OpenList v4.2.6 与回环 TLS 实测同一批准的合成样本。样本 `guize-fresh-de8ad3f-v1-base-64m` 为 67,108,864 字节，SHA-256 为 `9a30d2bb1a4f1eabcb41baa5b6518628411ba8ac668fc1e7085983261aa5f419`。开始前校验原件与实际挂载副本，OpenList 二进制 SHA-256 为 `64d4f1af1097b8bccf9d6d43f9d05a1b83df50d49e4ccf3d8151a5bea7d53742`。

| 实际请求 | 结果 |
| --- | --- |
| 完整读取 | HTTP 200，返回 67,108,864 字节，摘要与原件一致。全量覆盖 64 条源读取记录，单次读取峰值 65,536 字节。 |
| Range 及匹配的 If-Range | 均为 HTTP 206，分别返回相同的 130,084 字节。第二次命中缓存，无新增源传输。 |
| 固定限流窗口 | 1.25 秒内前四次为 HTTP 206，第五次为 HTTP 429，零响应字节。平稳阶段无新增源传输。 |
| 常规身份边界及直接源 | 三种无有效播放授权的请求均为 HTTP 403，零响应字节。直接 OpenList 匿名请求为 HTTP 401，零响应字节。 |

通过 [仓库入口](../../../poc/POC-07-public-network/run_local_replay.py) 执行，未使用小样本标记。以隔离 OpenList 只读挂载、临时 TLS 信任材料、区间 1024–131107、固定限流参数和批准样本复跑。调用方以 `/usr/bin/time` 测得含校验和采集的 Python 进程峰值 RSS 为 87,144 KiB。OpenList 的进程峰值 RSS 为 100,704 KiB。该数据记录这一次配置的实测水位。

11 个 TLS 请求均验证 TLS 1.3。共 12 对原始 HTTP 响应与响应体保留在本地证据归档。归档 135,826,505 字节，SHA-256 为 `2b1e502ec63694750c4077b37b562eda6e2a4caa5ec3117af397b48a6af5e144`。重新读取归档逐项核对全部 24 个文件。两个实验入口、进程和临时资源均已回收。

本次覆盖固定样本、回环播放入口和直接来源。管理入口、Worker 产物访问及公网环境由对应实际接口和实验继续验证。POC-007 正式结论仍待完整证据和独立审查。

## 管理与产物路径预检

在同摘要的真实 OpenList v4.2.6 中创建两个独立挂载和普通测试账户。使用文档中的只读管理接口时，管理员的 HTTP 和业务代码均为 200。普通来源账户收到 HTTP 200 和业务代码 403，57 字节响应未包含受保护记录。产物账户通过 WebDAV 读到独立挂载中 32 字节的合成产物，摘要为 `b1e5a1982b4ebd029dc7379ec72826747e326b0c614966b53b1765d115358cc7`。普通来源账户访问其自身挂载中的同名对象返回 HTTP 404，9 字节响应未包含该产物。服务、身份和临时目录均已回收。[OpenList 管理接口](https://openlistteam.github.io/docs/zh/guide/api/admin/storage.html)

本地验收要求在受控入口得到明确 HTTP 拒绝与无受保护内容。原生管理 API 在业务层拒绝，独立挂载在来源账户的命名空间中返回未找到。正式验收应使用归泽中实际执行管理身份和 TASK 产物授权的入口，以对应请求验证明确拒绝及响应字节。这两项按各自入口留证，已核验的 64 MiB 播放与来源证据继续按原配置复用。

通过 [独立的本地入口命令](../../../poc/POC-07-public-network/run_local_resource_replay.py) 接入同版本真实 OpenList。四次请求实测中，管理授权和产物样本 Grant 均返回 HTTP 200。产物读回 32 字节且匹配原件摘要。普通测试身份访问两个受控入口均获 HTTP 403、零响应字节。管理和产物各发生一次真实源读取，全部来自获准请求。命令退出 0，临时凭据未出现在测量结果，隔离进程及目录已回收。

这一组合预检验证了明确拒绝与零新增源读取可以随实际权限边界提供。POC-007 正式验证仍须固定资源窗口、独立身份和原始响应证据，真实 Worker 集成时另行验收。
