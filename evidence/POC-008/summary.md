# POC-008

前端框架比较登记。

## 实验输入准备

合成数据和交互动作按原十个等价场景组织。虚拟列表可按窗口读取百万行范围。三个 Node.js 小用例验证数据稳定性、窗口边界和场景结构。正式比较使用准备好的 Vue 与 React 两套原型，在统一环境审批后完成原十三项测量。

## 原型与采集准备

React 和 Vue 各自构建独立输出，从同一份固定样本运行十个场景。本地浏览器读回共 64 个动作，20 份原始记录逐一通过对应 JSON Schema。两份本地编译记录都包含四个实际输出，并逐一核验字节和 SHA-256。
