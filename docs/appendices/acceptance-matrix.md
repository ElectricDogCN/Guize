# 验收矩阵 / Acceptance Matrix

## GZ-021：本地完整 V1 与异构媒体执行

本表 AC-* 是补充场景索引，不能替换机器基线 `验收V1-0001`～`验收V1-0012`。`local-v1` 与 `production` 都保留原 10 项需求、12 项验收与共享安全义务；执行证据必须绑定范围/version/revision。AC-008 的原 500GB 场景属于 production，本地对应实际配置的正数水位与在途容量预留，不修改生产阈值。

| 补充场景 | 两个范围都必须验证的行为 |
|---|---|
| 并行跨度乱序完成 | 同组配置与完整拼接通过；播放窗口连续 READY、无洞 |
| 旧尝试/重复完成/取消后回报 | 当前 fencing 单次发布；旧产物隔离 |
| 后台饱和时播放/seek | 预留槽、公平/预算、旧需求失效与媒体回退 |
| Manifest/init/分片/缓存命中 | 鉴权、过期/撤权、跨用户隔离、禁止直达源站 |
| 本地 OpenList 中断/淘汰 | 保持资产/保留/正式副本，部分对象不能提升 |
| 本地结果改标 production | 范围配置、资源与测量绑定校验拒绝 |

POC-006 local-v1 仅对通用 OpenList 协议形成有范围的结论，百度真实生产义务继续延后；A380/ESXi、TrueNAS/iSCSI/ZFS、700TB、500GB 与公网外部可达仍等待生产证据。
